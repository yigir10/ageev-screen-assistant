# Stealth AI Screen HUD Overlay

Tauri v2 + Svelte 5 (Runes) + SvelteKit static + Tailwind v4 + Rust. Только Windows 10 2004+ / 11.

## Запуск

1. Установите: Node 20+, Rust (stable, MSVC), WebView2 (есть в Win 11).
2. `npm install`
3. Иконки (нужны для сборки): `npm run tauri icon путь/к/иконке.png`
4. Разработка: `npm run tauri dev`. Сборка: `npm run tauri build`.

## Хоткеи по умолчанию

| Действие | Бинд |
|---|---|
| Весь экран | Ctrl+Alt+1 |
| Выделить область | Ctrl+Alt+2 |
| Ghost ⇄ Interactive | Ctrl+Alt+3 |
| Очистить разметку | Ctrl+Alt+4 |
| Остановить ответ | Ctrl+Alt+5 |
| Следующий пресет | Ctrl+Alt+6 |
| Показать / скрыть | Ctrl+Alt+H |

Меняются в Interactive → ⚙ → Хоткеи, сохраняются в localStorage. Esc отменяет выделение.

## Заметки

- Игры должны работать в borderless windowed: поверх exclusive fullscreen оверлей не рисуется.
- Stealth (WDA_EXCLUDEFROMCAPTURE) скрывает окно от OBS, Discord, записи экрана и собственных скриншотов.
  При выключенном Stealth UI на время захвата прячется автоматически.
- API-ключи хранятся в Windows Credential Manager (если оно недоступно, временно падают в localStorage).
- Иконка в трее: клик — Ghost ⇄ Interactive; меню — настройки, показать/скрыть, выход. Второй запуск программы открывает Interactive в уже работающем окне.
- Автозапуск с Windows включается в настройках → Система.
- Выделение области работает по «замороженному» кадру: экран не меняется, пока вы выделяете.
- Разметка: модель рисует стрелки/рамки/точки; на скриншот накладывается координатная сетка для точности (отключается в настройках).
- Запросы к ИИ автоматически повторяются при 429/5xx и сетевых сбоях; в чате есть кнопка «↻ Повторить».
- Ширина панели меняется перетаскиванием правого края в Interactive.
- Первый запуск открывает мастер настройки (провайдер, ключ, проверка соединения, хоткеи).
- Ошибки показываются понятным текстом (регион, ключ, лимит, модель) с подсказкой, что делать. «Проверить ключ» есть в настройках.
- В Ghost Mode вверху экрана появляется пилюля «Снимаю… / Думаю… / Пишу ответ…».
- Пресеты запросов (Объясни, Реши, Найди ошибку, Переведи, Кратко) редактируются в ⚙ → Пресеты; в чате клик по пресету сразу задаёт вопрос по текущему скриншоту.
- История диалогов (🕘): хранится только текст, можно открыть, удалить, скопировать как markdown.
- Установщик: `npm run tauri build` (файл в `src-tauri/target/release/bundle/nsis`) или GitHub Actions: `.github/workflows/build.yml`.
- Если `cargo` ругается на API крейтов `xcap` / `windows` (у них часто меняются сигнатуры),
  поправьте версии в `src-tauri/Cargo.toml` под актуальные.
